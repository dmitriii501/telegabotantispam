## Что будет нашим отличием
1. **Правила словами с действием у каждого.** «Рекламу — бан, политику — удалять, оскорбления — предупреждать».
2. **Владелец видит, что происходит:** пробный режим с примерами, объяснение удаления, апелляции, очередь сомнительного.
3. **Понимание комментариев:** типы, тон, горячие клиенты, вопросы без ответа, ссоры. У классических ботов этого нет совсем, у ИИ-ботов нет такой аналитики.
4. **Контекст поста:** правила вроде «не по теме поста».
5. **Скорость и цена:** Jev отвечает быстро, примерно $2,4 в месяц за 1000 комментариев в день.

## Что добавить, чтобы не проигрывать по базовым ожиданиям
**P0 выполнен:** капча «я человек», проверка профиля новичка с базой аватарок, списки ссылок, учёт стикеров и медиа в антифлуде.
То, что осталось из ожиданий рынка, ниже.

**P1 выполнен:** защита от рейда, удаление служебных сообщений, строгая проверка первого комментария, чтение текста на картинках и стикерах, перенос настроек между чатами.

**P2:** ночной режим, жалобы участников, приветствия, автоответы и база знаний, второй язык интерфейса, «богатые» форматы.
